# @moneta/web

React + TypeScript web app of Moneta (Vite). See the repo [README](../../README.md) and
[docs/PLAN.md](../../docs/PLAN.md) (section "apps/web").

```sh
npm run web                    # from the repo root; /api is proxied to MONETA_API_URL (default :8080)
npm run build -w @moneta/web   # production build into dist/
```
